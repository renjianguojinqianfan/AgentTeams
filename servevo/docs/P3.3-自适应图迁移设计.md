## 1. 目标

单 Worker（servevo-coach 陪练官原型）能对主岗执行**陪练闭环**：刁钻客户剧本 → 主岗应答 → 评估 → 策略调整 → 循环；并可执行**回归测试**（预置测试集）。产出陪练报告 + 决策轨迹（可审计）。

## 4. 双模式设计

- **coach 模式**：LLM 驱动 ReAct 循环。init_context → agent_loop（LLM 决策工具）→ execute_tool → merge → 回边 agent_loop。确定性编排：已有待评估剧本 → 自动 evaluate_answer（主岗应答用注入 main_agent，真实接入即 Worker）。HITL：approval_mode 开启时剧本出题 interrupt 等审批。
- **regression 模式**：确定性编排，不靠 LLM 出题。逐题构造 evaluate_answer 工具调用，预置测试集跑完算通过率（score>=7）。对齐规划"v1/v2 差异=确定性，不赌 LLM"。

## 5. 主岗应答 mock（四准则）

`_mock_main_agent(scenario, category) -> str` 确定性 mock，与真实 Worker 同签名。真实接入时注入 async main_agent 桥接 Worker/rag。避免 LLM 工具调用顺序发散导致闭环不可复现。
