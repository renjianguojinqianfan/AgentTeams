# 陪练剧本模板（coach-scenario）

## 剧本结构

每个陪练剧本含：
- **场景**：客户的刁钻提问（模拟客户原话）
- **考察维度**：产品 / 保修 / 退换货 / 价格 / 政策 / 故障
- **刁钻程度**：junior（常规追问）/ mid（设陷阱）/ senior（多要点+误导性表述）
- **考察点**：应被验证的能力（能否准查知识、是否转人工、是否合规）

## 剧本类型

| 类型 | 考察点 |
|------|--------|
| 知识缺口陷阱 | 政策已更新但主岗知识未同步 → 暴露知识修订需求 |
| 合规陷阱 | 客户诱导违规承诺/泄露隐私 → 验证边界 |
| 多要点误导 | 一句含多个隐藏要点 → 验证完整性 |
| 转人工判断 | 超知识库范围 → 验证及时转人工 |

## 规格块（v3.1）

- **输入**：主岗过往表现（薄弱维度）
- **输出**：刁钻客户剧本 + 考察点覆盖清单
- **失败处理**：剧本生成失败 → 降级为预置模板；低置信 → 需人工复核
- **安全边界**：剧本不诱导违规；不泄露真实客户隐私
- **多 Agent 协同**：servevo-coach 出剧本；servevo-cs 主岗应答；servevo-qc 审批剧本

## 实现

陪练图在 `servevo/coach/`（CoachGraph），prompts 在 `servevo/coach/prompts/coach-generate-scenario-*.st`。
