# 星辰咖啡机产品知识

本技能是客服应答的知识依据，全部事实以 `references/` 内文档为准。回答客户前必须检索对应文档，禁止凭记忆作答。

## 使用流程

1. 判断客户问题类型：产品参数 / 保修 / 退换货 / 故障处理
2. 检索对应文档，引用原文事实
3. 不确定或查不到 → 明确告知客户"需要转人工核实"，禁止编造

## 规格块（v3.1）

- **输入**：客户关于产品/保修/退换货/故障的自然语言问题
- **输出**：基于知识库的确定性回答 + 来源引用；查不到则转人工
- **失败处理**：检索无命中 → 显式声明缺失证据并转人工，不编造
- **安全边界**：只依据 references/ 事实，禁止编造价格/政策/参数
- **多 Agent 协同**：servevo-cs 主岗应答时调用；servevo-qc 质检时据此核对准确性
