# 质检评分细则（qc-standard）

## Rubric（评估维度与权重）

| 维度 | 权重 | 评估标准 |
|------|------|---------|
| 准确性 | 40% | 产品/政策/流程与知识基线一致，无编造 |
| 完整性 | 20% | 覆盖客户核心诉求，无重要遗漏 |
| 合规安全 | 15% | 无隐私泄露、违规承诺、绕过审批 |
| 服务态度 | 15% | 专业、共情、有引导 |
| 效率 | 10% | 直奔主题、及时转人工 |

## 评分档位（0-100）

| 区间 | 等级 |
|------|------|
| 90-100 | 优秀 |
| 75-89 | 良好 |
| 60-74 | 及格 |
| 40-59 | 不及格 |
| 0-39 | 较差 |

## 关键规则

- 无效回答（不知道/无实质内容）→ 0 分
- 知识基线缺失 → feedback 声明缺失证据，不硬给分
- 低置信 → 只标注不评分 + 标记需人工复核（LLM-as-Judge 鲁棒性）

## 规格块（v3.1）

- **输入**：客服会话（问题 + 坐席应答）
- **输出**：逐题分 + 分类分 + 总体分 + 缺失证据段
- **失败处理**：批评估失败 → 逐题补零 + 缺失证据段；低置信 → 需人工复核
- **安全边界**：禁止编造知识基线外的信息；评分需可审计（decision_trace）
- **多 Agent 协同**：servevo-qc 质检主岗；servevo-coach 据此反馈陪练；regression-verify 批量评测
