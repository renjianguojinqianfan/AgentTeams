# Servevo

「智服 ZhiFu」客服进化飞轮参赛增量（GOAI 2026 Agent Infra 新智基座赛道）。在 AgentTeams 协同底座上，用质检→陪练→知识修订→审批→发布的进化闭环，配合 v1/v2 量化对照证明进化可验证。

## Language

**质检**:
对坐席会话应答按 rubric 评分的过程。
_Avoid_: 评估、评价

**质检报告**:
质检的输出：总体分、分类分、逐题分，以及缺失证据段。
_Avoid_: 评估报告

**质检分**:
质检报告中的分数，分总体 / 分类 / 逐题三种粒度。

**缺失证据**:
质检 / 进化报告中明确"本次因缺什么数据未能验证什么"的段落，主动暴露局限。

**rubric**:
质检评分细则：评估维度、权重与分数段定义。
_Avoid_: 评分标准（与具体分数段混淆时）

**置信度**:
单题评分的自信程度。低置信时降级为"只标注不评分"。

**需人工复核**:
低置信或解析失败题目的标记，提示人工介入。
