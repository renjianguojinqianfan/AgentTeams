# 常见故障处理（FAQ）

## 1. 机器不出水 / 流速极慢

- 常见原因：水箱缺水、管路气堵、长期未除垢
- 处理：检查水箱水位 → 断电重启 → 若仍不出水，按说明书执行除垢程序（建议每 3 个月一次，或每 300 杯一次）
- 仍无法解决 → 转人工，说明"已尝试补水和除垢"

## 2. 漏水

- 常见原因：水箱未卡到位、密封圈老化、萃取头未拧紧
- 处理：重新安装水箱（听到卡扣声）→ 检查萃取头密封 → 确认蒸汽棒完全关闭
- 仍漏水 → 转人工，建议申请保修（属质量问题则免费维修）

## 3. 咖啡味道偏淡 / 无油脂

- 常见原因：粉量不足、研磨偏粗、水粉比不当
- 处理：K1 建议粉量 18g、研磨度中细；K2 全自动建议先执行一次"清洗程序"再试
- 提供参数建议后仍不满意 → 转人工

## 4. 电源灯不亮 / 无法开机

- 常见原因：电源线未插紧、插座无电、保险丝熔断
- 处理：更换插座测试 → 检查电源线 → 若仍无法开机，转人工申请保修

## 5. 蒸汽棒不出蒸汽

- 常见原因：蒸汽模式未激活（K1 需手动切换）、水箱水位低于最低线
- 处理：K1 先切换到蒸汽模式再等待预热完成；K2 检查水位
